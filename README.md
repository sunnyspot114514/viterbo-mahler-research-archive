# Viterbo Mahler Research Archive

Independent researcher **Xiwei Chen**'s AI-assisted research archive, assembled for review on **2026-10-07**. It contains written analytic proof candidates for specified restricted classes, exact computational certificates, historical reports, and replay sources. It makes no claim to prove the general Viterbo or Mahler conjecture, establish priority over OpenAI, or provide independent mathematical certification.

The selection preserves **60 original files, 9,803,805 bytes**: 59 original-research files and one separate external-review archive. Seventeen duplicated ZIP payloads and five duplicated loose files are represented by retained archives rather than copied again. The latest v61 payload is also exposed as 15 unmodified browsable files. Earlier missing generators and lower-layer certificates remain missing.

File sizes, SHA-256 hashes, and the v61 archive payload were checked during assembly. **No mathematical verifier was run for this packaging pass.** Stored PASS strings and replay outputs are archival records. Some historical replay instructions depend on their original environment; this is not a verified one-command replay release.
